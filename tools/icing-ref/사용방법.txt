김해공항 노면 결빙 예측 (시험판)

1. 준비 (처음 한 번)
   - 파이썬 3 설치 (설치 시 "Add Python to PATH" 체크)
   - 명령 프롬프트에서:  pip install flask requests
   - 공공데이터포털(data.go.kr)에서 "기상청_단기예보 ((구)_동네예보) 조회서비스" 활용신청
     → 마이페이지의 "일반 인증키(Decoding)"를 config.json 의 service_key 에 붙여넣기
     (승인 직후에는 1~2시간 정도 호출이 안 될 수 있음)

2. 실행
   - 이 폴더에서:  python app.py
   - 브라우저가 http://localhost:5050 으로 자동으로 열림
   - 정오 이후에는 '내일 아침', 그 전에는 '오늘 아침'을 기본으로 판정
   - 판정할 때마다 결과가 판정기록.csv 에 쌓임 (다음 동절기 기준 보정용)

3. 단계
   위험  제설제 사전 살포 권고
   주의  새벽 순찰로 결빙 확인, 살포 대비 (조건은 충족했으나 조기 회복·강풍 등으로 하향)
   관심  결빙 조건에 근접, 예보 변화 확인
   정상  결빙 조건 없음

4. 판정 기준 (icing_rules.py 의 CONFIG 에서 조정)
   결빙형: 전날 12~24시 비 2시간 이상, 마지막 비 18시 이후,
           새벽(00~08시) 0℃ 이하, 그 시간 기온-이슬점 차 2.5℃ 이하
   강수형: 전날 18시~09시 최저 0℃ 이하, 2℃ 이하 강수 2시간 이상,
           강수 중 기온-이슬점 차 3.5℃ 이하
   하향:   일출 07:00 이전 + 07~09시 맑음 + 09시 3℃ 이상 → 주의 (결빙형만)
           결빙 시간대 평균풍속 6m/s 이상 → 주의 (결빙형만)

5. 역검증 (기준을 바꿨을 때 다시 확인)
   python backtest.py RKPK__1_.csv RKPK.csv
   → 기록 확보 기간 결빙 대응 6건 적중 여부와 경보일 목록 출력

6. 문제 해결
   - "인증키" 오류: Decoding 키인지, 활용신청 승인됐는지 확인
   - SSL 인증서 오류(사내망): config.json 의 verify_ssl 을 false 로 바꿔 시험
   - 포트 충돌: config.json 의 port 변경
